# 竣工环境保护验收监测报告表 — 标准结构（表一~表八）

> 本文件定义**验收监测报告表**（报告表格式，适用于环评报告表项目）的章节结构。
> 结构依据：阪田油墨（中山）有限公司新建项目（二期）验收监测报告（2026 年）
> 及《建设项目竣工环境保护验收技术指南 污染影响类》（生态环境部公告 2018 年第 9 号）。
> 与 `report_template.md`（验收报告书八章）互补：报告书适用于环评报告书项目，
> 报告表适用于环评报告表项目（内容更精简，监测部分占比更大）。

## 〇、22 份真实报告共性章节统计（skill_learn 学习结果）

> 以下为 2026-08 对 22 份广东中山地区验收监测报告/验收意见（含阪田油墨、美创工艺、
> 美蓓亚、嘉靖塑料、双实五金、坤聚五金、瑞康电器、森淼金属、恒发、樱雪、港联华凯等）
> 批量 OCR 解析后提炼的章节出现频率，指导模板权重与必填项判断。

- **必填高频章节（≥18/22）**：污染源（20）、审批决定（20）、总量（20）、防治措施（19）、变动情况（18）
- **常见章节（10-16/22）**：监测结果（16）、验收监测结论（10）、验收意见（10）、工艺流程（9）、
  环境影响报告表主要结论（9）、监测点位（9）、其他需要说明（9）、污染物处理（8）、原辅材料（7）
- **要点**：
  - 监测点位与监测结果章节高度依赖检测报告来源，编制时需同步采集检测报告编号与监测数据表。
  - 验收意见作为独立文件（验收意见+其他需要说明的事项）出现率 10/22，报告表通常不内嵌，需单独生成。
  - "变动情况"出现 18/22，说明多数项目存在与环评批复的差异，务必逐项核对并说明是否构成重大变动。

## 一、封面

- 标题：XX项目竣工环境保护验收监测报告表
- 项目名称 / 建设单位 / 编制单位 / 日期
- 建设单位法人代表、编制单位法人代表、项目负责人
- 建设单位：联系人、电话、邮编、地址

## 二、正文八表结构

### 表一 验收监测依据及评价标准

1. **项目基本信息表**（表1-0）：
   - 建设项目名称、建设单位名称、建设项目性质（新建/改扩建/技改/迁建）
   - 项目地点、主要产品名称、设计生产能力、实际生产能力
   - 开工建设时间、调试时间、验收现场监测时间
   - 环评报告表编制单位、环评批复审批部门
   - 环保设施设计单位、环保设施施工单位
   - 投资总概算、环保投资总概算及比例、实际总概算、实际环保投资及比例
2. **验收监测依据**：
   - 法律法规：环境保护法、水污染防治法、大气污染防治法、噪声污染防治法、
     固废污染环境防治法、建设项目环境保护管理条例（国务院令第682号）、
     建设项目竣工环境保护验收暂行办法（国环规环评〔2017〕4号）、
     污染影响类验收技术指南（公告2018年第9号）、地方法规（如《广东省环境保护条例》）
   - 项目文件：环评报告表、环评批复（文号）、验收监测委托书、检测报告（报告编号/日期）
3. **验收监测评价标准、限值**：
   - 废水评价标准（如 DB44/26-2001 第二时段三级标准）及限值表（表1-1）
   - 废气评价标准（有组织/无组织/厂区内）及限值表（表1-2）
   - 噪声评价标准（如 GB12348-2008 3类）及限值表（表1-3）
   - 固废贮存标准（GB18599-2020 / GB18597-2023）
   - 总量控制指标（根据环评批复，可能无总量要求）
4. **其他审批要求**

### 表二 工程建设内容

1. **工程建设内容**：地点、面积、产品、工艺、定员、班制、四至情况
2. **项目工程组成**（表2-1）：工程类别（主体/辅助/公用/环保工程）、项目名称、
   环评审批建设内容和规模、二期建设后全厂情况、备注
3. **产品规模、原辅材料、生产设备**：
   - 产品规模一览表（表2-2）：环评审批年产量 / 一期已验收产能 / 本次二期验收产能
   - 原辅材料用量一览表（表2-3）：序号、名称、环评审批年用量、一期年用量、本次二期验收年用量、备注
   - 主要生产设备一览表（表2-4）：设备名称、环评审批数量、一期已验收数量、本次二期验收数量、备注
4. **能耗情况**：全厂年耗电量等
5. **给排水情况**：生活给排水、生产废水、冷却水，用水排水一览表（表2-5）、水平衡图（图2-4）
6. **主要工艺流程及产污环节**：工艺流程图（图2-5）、工艺情况说明
7. **项目变动情况**（表2-6）：类别、环评内容、实际建设情况、变化原因及影响分析、结论
   （是否属于重大变动；不属于的说明依据，如填报环评登记表备案）

### 表三 主要污染源、污染物处理和排放

（附处理工艺流程示意图，标出废水、废气、厂界噪声监测点位）

1. **废水**：生活污水（处理工艺流程图）、生产废水（委托转移处理）
2. **废气**：有组织废气（集气罩→布袋除尘/活性炭吸附→排气筒）、无组织废气；
   处理工艺流程示意图（图3-2），标注监测点位
3. **噪声**：防治措施（低噪设备、隔声、减振、合理布局、绿化、时间控制）
4. **固体废物**：生活垃圾、一般固废、危险废物；
   固废产生量及去向汇总表（表3-1）
5. **其他环境保护设施**：
   - 环境风险防治措施（应急预案及备案编号、围堰、防渗）
   - 规范化排污口、监测设施及在线监测装置（排放口编号，如 DA001/GF-001）

### 表四 建设项目环境影响报告表主要结论及审批部门审批决定

1. **建设项目环境影响报告表主要结论**（环评结论概述）
2. **审批部门审批决定**（批复文号/日期）
3. **环评批复落实情况表**（表4-1）：类别、批复要求、实际建设情况、落实情况
   （逐条对照，类别含建设内容/废气处理措施/废水处理措施/固废处理措施/噪声防治措施/应急预案）

### 表五 验收监测质量保证及质量控制（本节内容来源于检测报告）

1. **质量保证和质量控制**：采样/分析方法、仪器校准、平行样/质控样/空白样要求
2. **人员资质**（表5-1）：姓名、职务、上岗证编号
3. **质控结果**：
   - 废水室内平行双样测定结果（表5-2）
   - 废水现场平行双样测定结果（表5-3）
   - 废水质控样测定结果（表5-4）
   - 废水室内/现场空白测定结果（表5-5/5-6）
   - 大气采样器流量校准结果（表5-7）
   - 噪声校准结果

### 表六 验收监测内容（本节内容来源于检测报告）

1. **监测项目、监测点位、因子及频次**（表6-1）：样品类型、采样点位、检测项目、样品状态、采样依据
2. **监测分析方法、使用仪器及检出限**（表6-2）：样品类型、检测项目、检测方法、分析仪器、检出限
3. **监测点位示意图**（图6-1）：标注废水/有组织废气/无组织废气/厂界噪声监测点位

### 表七 验收监测期间生产工况及结果（本节内容来源于检测报告）

1. **验收监测期间生产工况记录**：监测期间生产负荷（≥75%），生产负荷表（表7-1）
2. **验收监测结果**：
   - 废水监测结果及评价（表7-2）：采样点位、日期、项目、各次测定值、范围值、标准限值、评价
   - 废气监测结果及评价（有组织/无组织/厂区内）
   - 噪声监测结果及评价
3. **污染物排放总量核算**（实际 vs 审批）

### 表八 验收监测结论

1. **污染物排放监测结论**：废水/废气（有组织、无组织）/噪声/固废/总量 逐项达标结论
2. **应急措施**（应急预案备案情况）
3. **建议**（后续环境管理要求）

## 三、报告书/报告表差异说明

| 维度 | 验收报告书（report_template.md） | 验收监测报告表（本文件） |
|---|---|---|
| 适用项目 | 环评报告书项目 | 环评报告表项目 |
| 章节形式 | 八章正文 | 表一~表八 |
| 监测内容占比 | 较低（第四章概括） | 高（表五~表七为检测报告来源） |
| 验收意见 | 独立章节 | 独立文件（验收意见+其他需要说明的事项） |
| 工程变动 | 二章说明 | 表二第7项（含变动分析表） |

## 四、验收意见（独立文件，验收意见+其他需要说明的事项）

- 标题：XX项目竣工环境保护验收意见
- 验收依据与验收组组成说明（对照暂行办法/技术规范/环评及批复）
- 一、项目建设基本情况（建设地点、规模、主要建设内容；建设过程及环保审批情况）
- 二、工程变动情况
- 三、环境保护设施建设情况
- 四、环境保护设施调试效果
- 五、工程建设对环境的影响
- 六、验收结论（验收组同意通过环境保护验收）
- 七、后续要求
- 验收组成员签字
- 其他需要说明的事项：验收过程简介、公示情况、信息公开、遗留问题说明
