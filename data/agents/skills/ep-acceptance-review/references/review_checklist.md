# 竣工环保验收报告 审核检查清单（P0/P1/P2 三级）

审核三维度：**图片 / 格式 / 内容细节**。每项标注检查方式：
`[脚本]` = check_acceptance_docx.py 可自动判；`[AI]` = 需 AI 读图或语义判断；`[脚本+AI]` = 脚本初筛 + AI 复核。

## 一、P0 致命（存在任一项 ⇒ 打回重做，不得出具）

| 编号 | 检查项 | 说明 | 方式 |
|---|---|---|---|
| P0-1 | 必备三件套缺失 | 环评报告、环评批复、CMA 验收监测报告 三件套信息或附件缺失（生成技能已门控，外部报告需核对） | [脚本] |
| P0-2 | 重大变动未说明 | 性质/规模/地点/工艺/防治措施发生重大变动但无重新报批说明 | [AI] |
| P0-3 | 不通过情形却结论通过 | 存在未验先投、无证排污等《暂行办法》第八条情形，验收结论仍写"通过" | [AI] |
| P0-4 | 监测数据超限未评价 | 排放数据超过标准限值，正文/结论未作任何说明 | [AI] |
| P0-5 | 监测数据缺失/编造 | 关键污染物无数据，或数据与 CMA 报告明显不符（无法核对时标"待人工确认"，不直接判 P0） | [AI] |
| P0-6 | 报告主体错误 | 建设单位名称、项目名称与批复不一致且无说明 | [AI] |

## 二、P1 严重（存在任一项 ⇒ 修改后复审）

### 图片类（本技能重点）

| 编号 | 检查项 | 说明 | 方式 |
|---|---|---|---|
| P1-1 | 图片插错位置 | 地理位置图未入附图、批复扫件未入附件、设施照片未入对应章节（跨区错位） | [AI] |
| P1-2 | 图注与内容不符 | 图注写"地理位置图"实际放的是平面布置图/照片 | [AI] |
| P1-3 | 图片损坏/空白/重复 | 文件损坏打不开、空白图、同一张图重复插入多处 | [脚本+AI] |
| P1-4 | 图片方向颠倒/侧转 | 扫描件常见，导致内容不可读 | [AI] |
| P1-5 | 图片严重模糊/变形 | 分辨率过低、文字不可辨、拉伸变形 | [AI] |
| P1-6 | 附图/附件编号跳号重号 | 附图1、附图3（缺附图2）；两个"附件1" | [脚本] |
| P1-7 | 关键图件缺失未占位 | 无【图片待补充】占位却整图缺失，或占位框残留未替换 | [脚本] |

### 格式类

| 编号 | 检查项 | 说明 | 方式 |
|---|---|---|---|
| P1-8 | 章节缺失/顺序错乱 | 八章（基本情况/变动/设施/调试效果/环境影响/制度/结论/后续要求）+ 验收意见 + 附图/附件 缺章或乱序 | [脚本] |
| P1-9 | 占位符残留 | 正文、表格、图注残留【待补充】【待补充材料清单】 | [脚本] |
| P1-10 | 四张关键表缺失/结构错误 | 工程组成、验收产品、原辅材料、设备表 缺表或表头列数不符 | [脚本] |
| P1-11 | 正文与表格数据矛盾 | 总投资、环保投资、产能、规模等关键数字正文与表格不一致 | [脚本+AI] |
| P1-12 | 验收意见与正文结论矛盾 | 意见"通过"正文"不通过"或反之；意见缺六要素（基本情况/变动/设施/调试/影响/结论） | [AI] |
| P1-13 | 报告主体信息不全 | 封面/元信息缺建设单位、编制单位、日期 | [脚本] |

### 内容类

| 编号 | 检查项 | 说明 | 方式 |
|---|---|---|---|
| P1-14 | 数据三处不一致 | 关键数字在正文、表格、验收意见中不一致 | [脚本+AI] |
| P1-15 | 标准/限值引用错误 | 引用标准编号错误（如将 HJ 347.2 与 HJ 347.1 写反）、限值与污染物不对应 | [AI] |
| P1-16 | 监测点位/工况信息缺失 | 验收监测缺工况记录、监测点位说明 | [AI] |

## 三、P2 一般（仅 P2 ⇒ 建议修改后通过）

| 编号 | 检查项 | 说明 | 方式 |
|---|---|---|---|
| P2-1 | 字体字号不统一 | 标题非黑体/深蓝、正文非宋体小四、图注字号/颜色不统一 | [脚本] |
| P2-2 | 页面设置不规范 | 非 A4、页边距异常（标准：上下 1.0in、左右 1.1in） | [脚本] |
| P2-3 | 表格格式瑕疵 | 表头底色缺失、列宽失衡、表内文字溢出 | [脚本] |
| P2-4 | 错别字/标点/单位 | 单位符号大小写（mg/L、mg/m³）、标点全半角混用 | [AI] |
| P2-5 | 日期/文号格式 | 日期非"YYYY年M月D日"、文号格式不规范 | [AI] |
| P2-6 | 图注样式不统一 | 部分图有图注部分没有、图注位置不统一 | [AI] |
| P2-7 | 语句冗长/重复 | 同一内容在不同章节重复表述 | [AI] |

## 五、判定规则速查

1. 任一 P0 ⇒ 结论"打回重做"，意见单列全部问题。
2. 无 P0、任一 P1 ⇒ 结论"修改后复审"，P1 修复后需重跑全量检查。
3. 仅 P2 ⇒ 结论"建议修改后通过"，或用户确认接受后通过。
4. 无法程序化确认且 AI 无法判断的项 ⇒ 标"待人工确认"，不计入自动结论。
