# Acceptance Report Team ｜ 验收报告编制审核专家团

> 版本：1.0.0 ｜ 类型：Team 型专家团 ｜ 分类：合规审查
> 适用范围：《建设项目竣工环境保护验收报告》编制与独立审核

---

## 一、专家团是什么

一个"编制 + 审核"职责分离的自动化协作团队，帮你从零完成一份合规的
竣工环保验收报告，并在交付前经过独立审核把关。

| 角色 | 花名 | 职业 | 职责 |
|------|------|------|------|
| 主理人 | 严验之 | 质控总监 | 全流程编排、P0/P1/P2 裁决、复审循环、最终交付 |
| 编制专员 | 章成书 | 报告编制师 | 资料收集、必备三件套校验、生成 Word 报告 |
| 审核专员 | 何慎微 | 报告审核师 | 程序化检查 + AI 视觉核对 + 内容一致性比对，出具意见单 |

**核心管理理念**：编制与审核严格分离（对齐 CMA 三级审核思维）。
编制专员负责产出，审核专员独立把关，主理人只做编排与裁决。

---

## 二、能做什么

1. **编制**：把项目资料（环评、批复、CMA 监测报告、排污许可、图件等）
   整理为规范验收报告（八章正文 + 四张表 + 验收意见 + 附图/附件/现场照片），
   导出 Word（.docx），深蓝白金色政务公文风格。
2. **审核**：对报告做三层检查——
   - 程序化检查：章节完整性、占位符残留、附图/附件编号、图片有效性、
     四张关键表结构、字体页面设置、JSON 源数据一致性；
   - AI 视觉核对：逐张读图，核对图注与内容匹配、图片位置、方向、清晰度；
   - 内容一致性：正文 ↔ 表格 ↔ 验收意见关键数据、监测结论与证据匹配、
     法律风险项初判。
3. **修订闭环**：审核发现问题后自动退回编制师修改、重新生成、复审，
   直到通过或达到复审上限。
4. **仅审核**：你已有报告（自己编的或外部提供的），可直接只走审核环节。

## 四、你需要准备的材料（必备三件套）

| 材料 | 说明 |
|------|------|
| 环境影响报告书（表） | ★ 必备 |
| 环境影响评价批复 | ★ 必备，审批部门文号 |
| 验收监测报告 | ★ 必备，CMA 资质出具、盖 CMA 章 |

其余可选材料：排污许可证、危废合同与联单、应急预案及备案、
平面图/监测布点图/地理位置图、公示截图、厂区与设施照片等。

> **缺三件套时**：编制专员会输出《资料补齐清单》并暂停，补齐后自动继续，
> 不会生成"空壳报告"。

## 五、审核分级与结论

| 级别 | 含义 | 结论 |
|------|------|------|
| P0 致命 | 必备材料缺失、不通过情形却结论通过、超限未评价等 | **打回重做**，不得出具 |
| P1 严重 | 图片错位/图注不符、章节缺失、占位符残留、数据矛盾等 | **修改后复审** |
| P2 一般 | 字体字号、编号格式、错别字等 | **建议修改后通过** |

每次审核交付《报告审核意见单》：问题清单（级别/位置/描述/建议/来源）+
审核结论 + 修改指引（指明改哪个 JSON 字段或换哪张图）。

## 六、自动闭环边界（重要）

| 类型 | 处理方式 |
|------|----------|
| 可自动修复 | JSON 字段、占位符、格式、编号、章节 → 自动修订并复审，无需逐轮请示 |
| 需用户提供素材 | 图片缺失/错误、批复/监测数据没给 → 停下等您补齐后自动继续 |
| 需用户决策 | P0 法律情形（重大变动未报批、无证排污）、监测数据真实性 → 主理人暂停请示 |

复审上限 2 轮：仍未通过时停止并说明，避免无限打转。

## 九、常见问题

**Q1：专家团会一直自动改到通过吗？**
不会无限自动。可自动修复的问题会自动闭环；缺素材会停下等您；
P0 法律情形会暂停请示；复审最多 2 轮。

**Q2：审核专员会不会改我的报告？**
不会。编制与审核分离，审核只出意见单；修改由编制专员按意见执行。

**Q3：能审别人（外部机构）编的报告吗？**
可以。直接把 docx 发来走"仅审核"流程即可，可选附上源数据 JSON 增强一致性比对。

**Q4：监测数据会不会被 AI 编造？**
不会。编制/审核均以你提供的正式文件为准，无法确认的项标注"待人工核对"，
不会虚构数据与标准限值。

**Q5：怎么升级新版？**
联系打包方重新打包 zip 覆盖即可。zip 是快照，改动后需重新打包。
