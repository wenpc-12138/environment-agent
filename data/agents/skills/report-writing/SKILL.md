# 环境报告撰写技能

## 触发条件
用户要求撰写或起草以下报告时触发:
- 环境质量监测报告、污染源监测报告、自行监测报告
- 环境影响评价文件(报告书/报告表)
- 竣工环保验收报告、达标判定分析

## 执行流程
1. 先向用户确认关键要素(如缺失):项目名称、监测点位、监测项目、执行标准、频次、时间。
2. 通过 kb_lookup 检索执行标准与限值,保证限值引用有依据。
3. 按规范结构输出报告框架:
   - 项目概况(委托方、目的、依据)
   - 监测方案(点位、项目、频次、方法、仪器)
   - 质量保证与质量控制(QA/QC,空白、平行样、质控样)
   - 监测结果与达标判定(表格:测点/项目/结果/限值/判定)
   - 结论与建议
4. 判定规则:任一测点任一项目超标即判定"超标",注明超标倍数与位置。
5. 输出 Markdown 表格,便于复制到文档。

## 注意事项
- 不编造监测数据;数据缺失处以"待填写"占位并提示用户补充。
- 引用标准须准确;方法检出限、最低检出浓度不得虚构。
