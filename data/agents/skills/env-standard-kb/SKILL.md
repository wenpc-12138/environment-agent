# 环境标准知识库技能

## 触发条件
用户问题涉及以下任一关键词时,必须执行本技能流程:
- 污染物排放限值、浓度限值、监测方法、采样频次
- 环境空气质量/水环境/土壤/噪声/固废相关的标准(GB、HJ、行标、地标)
- 环保政策、法规、管理办法、技术导则
- 环评、验收、排污许可、自行监测

## 执行流程
1. 第一步:kb_lookup 检索本地知识库,关键词用"指标 + 介质 + 标准类型"组合,例如"SO2 锅炉 排放限值"。
2. 第二步:命中条目按相关度整理,直接引用;限值类数据须带标准号。
3. 第三步:本地未命中或需要最新版本时,web_search 联网检索,关键词追加"GB HJ 生态环境部"等限定词。
4. 第四步:对联网获得的权威资料执行 kb_save 落库:
   - 标准规范 -> category=standard
   - 政府发布(生态环境部/省市厅局文件、公告)-> category=gov
   - 政策法规(条例、办法、规划)-> category=policy
   - 一般网络资料 -> category=network
5. 输出:结论在前,标准依据在后;标准编号存疑时标注"待核实"。

## 五分类说明
| category | 含义 | 示例 |
|---|---|---|
| network | 网络资料 | 技术博客、机构页面 |
| gov | 政府发布 | 部委公告、地方文件 |
| standard | 标准规范 | GB/HJ/行标/地标 |
| policy | 政策法规 | 条例、办法、规划 |
| other | 其他 | 未归类资料 |
