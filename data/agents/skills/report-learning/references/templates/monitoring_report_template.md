# 环境监测报告 — 标准结构

> 通用环境监测/检测报告模板（报告书/报告表均可适用），结构覆盖：
> 委托监测、监督监测、自行监测、污染源监测、环境质量监测等。
> 依据《检验检测机构资质认定管理办法》及 CMA 报告要求。
> 章节频率为 skill_learn 对真实样本学习后的指导值（待补充）。

## 一、封面与声明
- 报告编号（唯一，可追溯）
- 项目名称 / 委托单位 / 受检单位 / 监测单位 / 报告日期
- CMA 章、签发日期、报告专用章
- 声明页（报告未经书面批准不得部分复制、检测结果仅对样品负责等）

## 二、正文结构
1. **监测目的**：委托/任务依据
2. **监测依据**：委托书、任务单、相关标准（HJ/GB/DB 方法标准）、环评批复等
3. **监测项目与点位**：
   - 监测点位布设表（点位编号、位置、样品类型、监测项目）
   - 点位示意图
4. **采样与分析**：
   - 样品状态、采样日期/时间、采样方法及依据
   - 分析方法、使用仪器及检出限表
5. **质量保证与质量控制**（QA/QC）：
   - 采样仪器校准/流量校准
   - 平行样、质控样、空白样测定结果
   - 人员资质表
6. **监测结果**：
   - 分介质结果表（废水/废气有组织/无组织/环境空气/噪声/固废）
   - 每表含：点位、项目、各次测定值、范围值、标准限值、评价（达标/超标）
7. **监测结论**：逐项达标判定、超标项超标倍数与位置
8. **其他**：工况说明（污染源监测时）、监测期间生产负荷表
