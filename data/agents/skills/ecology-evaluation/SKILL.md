# 生态现状评价技能

## 何时使用

- 用户要求编制生态现状评价、生态影响评价或生态专题。
- 涉及生物多样性指数、样方调查、栖息地/湿地/自然保护区分析。
- 矿山修复、流域生态修复、生态敏感区影响分析。

## 工作流程

### 第 1 步：明确评价范围与敏感目标

- 确认项目所在区域：自然保护地、生态红线、饮用水源保护区、重要湿地等生态敏感目标。
- 按《环境影响评价技术导则 生态影响》（HJ 19-2022）确定评价等级与范围。

### 第 2 步：调查与数据

- 植被：样方法（样方大小/数量按群落类型），记录物种、盖度、频度、多度。
- 动物：两栖/爬行/鸟类/哺乳类调查方法（样线/样带/红外相机）。
- 水生态：浮游植物/浮游动物/底栖生物采样与计数。

### 第 3 步：生物多样性指数计算

- 香农-维纳指数：H' = -sum(pi * ln(pi))，pi 为第 i 种个体占比。
- 辛普森指数：D = 1 - sum(pi^2)。
- 均匀度（Pielou）：J = H' / ln(S)，S 为物种数。
- 使用 calc_formula（formula_id: shannon-index / pielou-evenness / simpson-index）。

### 第 4 步：影响分析与评价

- 施工期/运营期对植被、动物、水生态的影响途径与程度。
- 生态损失量估算（面积/物种/生境），补偿与修复措施。
- 生态红线与敏感目标符合性结论。

## 交付

- 生态现状调查表（样方/物种/指数计算结果）+ 影响评价章节 + 修复措施清单。
- 数据来源标注（调查记录/文献/既有资料）。
